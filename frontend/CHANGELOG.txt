KISAN MITRA — 3D PORTFOLIO STYLE UPDATE
======================================

Visual additions
----------------
- New dark-first visual system with an optional light theme.
- Strong gradient headline treatment and refined page spacing.
- Floating glass navigation and translucent dashboard surfaces.
- Procedural 3D plant, glowing orbit rings and ambient particles.
- Scroll reveal and subtle pointer-based card tilt.
- Crop-image scanning animation.
- Responsive navigation, cards, forms and tables.
- Reduced-motion handling and visual fallback if WebGL is unavailable.

Functional compatibility corrections
-------------------------------------
- Set first-visit theme to dark while retaining persisted theme switching.
- Changed the crop-doctor initial login check to call getCropToken(), the
  helper actually declared in that module. This removes an unnecessary
  dependency on a getToken() global from another script.
- Retained current API hosts, routes, payloads, authentication token key,
  translation data and existing page element IDs.

Not changed
-----------
- No FastAPI backend, database, endpoint or environment configuration.
- No user-specific data or secrets.
- The original css/style.css is included unchanged.
